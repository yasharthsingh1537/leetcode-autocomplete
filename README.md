# LeetCode AutoComplete

An intelligent Chrome extension that provides
context-aware code autocomplete while solving
programming problems on LeetCode.

## Tech Stack

- TypeScript
- React
- Vite
- Chrome Extension Manifest V3
- pnpm

## Planned Features

- Context-aware code suggestions
- Variable and function completion
- DSA-related suggestions
- Code snippets
- Multi-language support

## Supported Languages

- C++
- Python
- Java
- JavaScript

## Development

Install dependencies:

```bash
pnpm install
```

Start development:

```bash
pnpm dev
```

Build:

```bash
pnpm build
```

Run tests:

```bash
pnpm test
```
